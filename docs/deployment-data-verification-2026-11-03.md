## 工具边界

`scripts/prepare-server-data.py` 默认只读预览，不在生产库执行迁移或资料写入。`--rehearse` 要求本机 MySQL 管理 socket 访问权，完整备份后在新建的 `kaoyan_deploy_verify_<随机值>` 库恢复。只对该隔离库执行缺失的 V13/V14 及公共资料事务，并清理本次隔离库；备份及SQL留在0700目录、0600文件中。存在部分V13、前置字段缺失、自定义触发器／例程／事件或非InnoDB表时拒绝自动预演。

同一学校按名称映射；专业按学校、专业、年份及完整登记备注区分学院和方向；题目按科目、题干及选项识别；公开资料按标题、科目与来源匹配。新记录分配目标库编号，版本快照及招生指标的关联编号同步映射；指标内容哈希按映射后字段重建，来源范围编号保留。已有题目答案、解析、来源或版本不一致时拒绝覆盖，不合并或替换历史作答。仅学校层次／省份差异进入明确的更新清单，其他公共记录复用或新增。

公共事务使用行锁、数量及完整行指纹保护；目标发生变化则失败并回滚。没有清空表、覆盖主键、重建个人记录、执行V1或旧种子的路径。生成的生产SQL仍须结合服务器预演报告、维护窗口及明确授权使用；工具本身没有生产执行模式。V13/V14为独立提交DDL，实际生产执行后若数据事务失败，新增空表可能保留，需要按真实状态处理。
