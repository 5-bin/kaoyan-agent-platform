# 刷题与错题功能说明

日期：2026-10-13。负责人边界：本功能负责人维护对应前端、Java接口、业务持久化和自动化测试；需要Python生成式错题辅导时与Agent负责人协作。公共枚举、认证、父POM、数据库迁移和Java→Python契约变更须提前协调。

## 范围与非目标

当前范围包括题目目录、章节／随机／错题／收藏组题、固定批次题序、草稿续做、两级审核提示、收藏、单选题确定性判分、幂等提交、错题归集与掌握状态、结果页和学习统计。

当前不包括正式题目审核发布、题目撤回和历史版本迁移、主观题判分、整卷考试、生成式答题前提示、Agent错题解释、PostgreSQL迁移及管理员题库页面。内置四科共12道题是待课程资料负责人复核的自编演示题，只用于工程验收。

## 数据与接口

核心实体为`Question`、`PracticeSession`、`PracticeSessionItem`、`PracticeAttempt`、`WrongQuestion`和`QuestionFavorite`。批次固定题目版本与顺序；作答保留题目、答案、解析和提示级别快照；错题和收藏按账号隔离。

| 接口 | 主要行为 | 验收重点 |
| --- | --- | --- |
| GET `/api/knowledge/points` | 按科目读取知识点 | 仅返回目录字段 |
| GET `/api/questions`、GET `/api/questions/{id}` | 按科目、知识点、难度分页筛选题目 | 提交前不泄露标准答案和解析 |
| POST `/api/practice-sessions` | 创建chapter、random、wrong或favorite批次 | 默认10题、范围1—50；actualCount真实；零题池返回400 |
| GET `/api/practice-sessions`、GET `/api/practice-sessions/{id}` | 查询本人批次、题序和进度 | 跨账号404；随机题序刷新后不变化 |
| GET `/api/practice-sessions/{id}/items/{itemId}` | 返回固定版本题干、选项、草稿和本人提交状态 | 未提交时不返回答案或解析 |
| PUT `/api/practice-sessions/{id}/progress` | 以expectedRevision保存题号和草稿 | 旧revision返回409；不能修改已提交或已结束项目 |
| POST `/api/practice-sessions/{id}/items/{itemId}/hints` | 获取level 1／2审核提示并记录使用 | level 2必须在level 1后；提示不泄露选项答案 |
| POST `/api/attempts` | Java确定性判分、保存作答并更新错题 | clientRequestId幂等；冲突或同项目重复提交返回409 |
| POST `/api/practice-sessions/{id}/finish`、GET `/api/practice-sessions/{id}/result` | 提前结束或读取已完成结果 | 未答不算错误；自动完成和重复结束行为稳定 |
| GET `/api/favorites`、PUT／DELETE `/api/favorites/{questionId}` | 查询、添加和取消本人收藏 | 添加／取消幂等；收藏与错题状态独立 |
| GET `/api/wrong-questions`、GET `/api/wrong-questions/{id}` | 查询本人错题和掌握状态 | 错答进入reviewing；连续两次无提示答对后mastered |
| GET `/api/attempts`、GET `/api/attempts/{id}` | 查询本人作答历史 | 保留历史快照；跨账号404 |
| GET `/api/study/summary` | 返回有效作答、去重题数、正确率、独立正确率、提示和知识点统计 | 日期按Asia/Shanghai且包含结束日；零分母返回null |

## 验收标准

1. 注册两个账号；账号A创建章节练习，账号B读取A的批次、作答和错题均得到404或空列表。
2. 题目列表、题目详情和未提交批次项目的JSON中不存在标准答案或解析字段。
3. 请求10题但候选不足时成功创建并返回真实actualCount；空错题／收藏题池返回`EMPTY_PRACTICE_POOL`且不创建空批次。
4. 选择答案后刷新页面，重新进入批次可恢复草稿和固定题序；使用旧revision保存返回`STALE_REVISION`。
5. level 2提示不能绕过level 1；提示使用写入作答，提示辅助答对不推进连续独立正确次数。
6. 服务端按固定题目版本判分；相同clientRequestId重放返回同一作答，不同内容复用编号返回`REQUEST_CONFLICT`，同一批次项目不能重复计数。
7. 错答自动进入错题本；之后连续两次无提示答对变为mastered；再次答错恢复reviewing。
8. 全部项目作答后自动完成；提前结束保留未答数，未答题不进入错题本。
9. 收藏可创建收藏练习，reviewing错题可创建错题重练；两个题池均只读取本人数据。
10. 批次结果和学习统计与已保存作答一致，总正确率和独立正确率口径分开。
11. 桌面和390px宽度下核心控件无重叠、无横向溢出，键盘可操作表单和按钮。
12. Java、Python、前端语法、文档检查及真实后端浏览器流程全部通过后才允许合并。
