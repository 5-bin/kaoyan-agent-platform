# 主题理解与题目语义检索验证

日期：2026-10-24。范围：当前adaptation工作区。用户已确认本地中文向量模型、独立Qdrant题目索引、本人错题／收藏及已发布全题库；不迁移日常数据库、不重启日常服务、不提交、推送或部署。

## 交付行为

- 通用句式提取主题，支持“涉及二叉树的题”“知识点：二叉树的题目加入收藏”等；词表仅补充识别。明确区分主题缺失、零匹配、索引准备中、构建失败与检索服务失败。
- 新增独立本地题目Qdrant。Java导出已审核且启用题目白名单，Python按完整公开快照与模型标识生成版本；旧索引保留，不在请求中删除。同步、状态和检索接口均需内部凭证。协议详见[学情助手契约](assistant-learning-contract.md)。
- Java先限制账号来源、科目及难度，再检索所有授权候选；标签匹配优先，其余按向量相似度排序。未答答案、解析和个人作答不参与匹配，历史覆盖只驻留内存，快照缺失明确提示。
- 读取、预览和操作使用Java固定的可信匹配集合。主题操作包括单题均先确认；显式Q引用兼容原流程。预览及确认核对当前内容、题目版本和来源标记，变化409；重复确认幂等。练习还要求匹配历史版本等于现行版本，避免按旧主题生成无关新题。
- 前端展示主题、题干节选及“知识点匹配／语义相关”标记，不展示相似度为概率。索引未就绪／服务失败时最后一问可重试，沿用授权和配额检查。零题不显示无关知识段落，也不生成操作。
- 无新增依赖或数据库迁移。当前服务只读已准备的本地模型文件，首次准备命令、独立索引配置及离线清理入口见[README](../README.md#本地题目语义检索)。模型与索引均被忽略，不提交权重或业务数据。

## 模型来源与效果限制

使用现有配置的[BAAI/bge-small-zh-v1.5模型](https://huggingface.co/BAAI/bge-small-zh-v1.5)，模型卡标示MIT许可；FastEmbed从`Qdrant/bge-small-zh-v1.5`提供的ONNX副本加载。下载缓存留在项目忽略目录，不复制权重到交付源码，未发生付费模型调用。

默认0.75是本次计划确定的工程阈值，不是领域准确率。实际记录中，“查找二叉搜索树的元素”匹配到“在二叉排序树中搜索给定元素”，而短查询“二叉树”漏掉若干无标签的长描述。标签可正常命中，但语义扩展仍可能漏题，不能声称“找到所有相关题目”。当前编码器会截断超过512 token的输入，长题存在额外漏检风险。

工程案例由本任务自编，预期相关性用于检查，不冒充人工领域审核、冻结评估集或学习效果。后续改阈值或模型应使用独立标注案例，保留本次失败例，不能通过降低阈值后忽略新增误匹配来宣称效果提升。
