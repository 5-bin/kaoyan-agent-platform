## 2. 使用模板

- 打开[Excel填写模板](../../outputs/collection-20261024-01a16dbb/资料收集模板.xlsx)，先填“来源”，再填对应业务页。字段的必填条件、允许值和现有字段映射见[字段字典](字段字典.md)。
- 5张收集表为：来源、院校、招生专业、知识资料、题目。“院校”同时登记逐校覆盖情况；另保留“分工与说明”“题库配额”“字段字典”辅助页面。仅5张收集表参与导入：第1行为英文机器字段，第2行为中文名称，**第3行起填写数据**。中文名后的`*`表示必填，`△`表示条件必填；蓝色表头为业务字段、灰色表头为审核字段。保留前两行，不合并单元格、不改字段名。
- 下拉及格式预设覆盖第3—502行，每页500条；更多数据可复制空白行的格式和验证，不保证粘贴内容会被Excel拦截，导入前仍须程序校验。全量院校的招生条目可能远超院校数，可按负责人拆成多个包，再统一合并。
- [5份CSV空模板](templates/)用于程序交接：UTF-8编码，只有第1行英文表头。若从Excel导出CSV，要删除中文名称行，不能连同前两行一起作为数据导入。院校表新增的覆盖字段用于采集跟踪，不直接写入现有业务表。
- 所有编号、专业代码、考试代码按**文本**保存。例如`081200`不能变成`81200`。年份为整数；日期为`YYYY-MM-DD`，Excel中使用日期值。人数为人、分数为分。
- 未知可选项留空；CSV空单元格转换为JSON `null`，不用`0`、`-`、`未知`代替数值。必填项缺失的行可留在草稿，不能进入发布包。
- 多值统一使用英文分号`;`，如`101;201;301;408`、`SRC-AB-001;SRC-AB-002`。导入时转换为数组，去掉首尾空白；正文不按分号拆分。
- 一格保存完整题干或解析，可使用单元格内换行。CSV含逗号、换行或双引号时必须按CSV规则引用，禁止手工拼接。知识正文使用独立UTF-8 Markdown文件，表内只填相对路径。
- 模板是普通输入表，不需要填写公式。以`=`、`+`、`-`、`@`开头的原文应按文本录入，导出和再次打开CSV时使用文本导入方式，避免被当作公式。不能以字符串拼接生成SQL。

## 3. 每类资料怎么收集

### 3.1 来源：先说明“从哪里来、能怎么用”

每份公告、目录、教材版本、课程讲义或原创作者记录各建一个`sourceId`。必填标题、作者／机构、精确定位、来源版本、获取日期、权限状态和权限依据；使用多份来源时在业务行关联全部编号，并在`locator`逐项说明，例如`examSubjects=SRC-AB-001@目录081200行；eligibility=SRC-AB-002@章程第六条`。

`url`应指向具体官方页或原文文件，不只填网站首页。只有本地授权文件时填写`filePath`和证据路径；当前Agent引用要求公开、无凭证的HTTPS链接，因此没有合适链接的资料暂存，不伪造链接。`publishedAt`是官方发布时间，查不到就空；`retrievedAt`是实际获取日期，不能混为一谈。动态页面额外记录查询年份、学院、专业及操作条件，允许留存时保留截图或PDF定位。

`permissionStatus`分为`PENDING`待确认、`ALLOWED`拟用方式已获允许、`LINK_ONLY`仅链接、`PROHIBITED`不允许。`permissionNote`写明允许的具体方式、署名要求、是否允许翻译／改编及公开展示；`permissionEvidence`填许可页或授权文件路径。公开可读不直接填ALLOWED；仅允许链接的来源不能自动复制正文、翻译题目或生成向量副本。官方招生事实可整理为简短事实记录，但不因此推断整页或附件可复制。

`fileSha256`由合并负责人针对本地实际证据文件计算，采集人可留空；没有文件就不填。不能把网页链接、Git blob哈希或随手写的版本号冒充文件SHA-256。证据仅按允许范围存放，不收集账号令牌和个人资料。

### 3.2 院校与招生专业：学校一行，招生组合一行

**院校范围已明确为全部985／211院校，不是“92所”。** 先以教育部公开的[985名单](https://www.moe.gov.cn/srcsite/A22/s7065/200612/t20061206_128833.html)与[211名单](https://www.moe.gov.cn/srcsite/A22/s7065/200512/t20051223_82762.html)建立并集、按学校身份去重，再冻结覆盖清单；不要把两份名单数量相加。双一流是另一分类，不能自行把所有双一流学校混入本次已确认范围。名单中旧名称、合并院校、多地办学、校区与独立招生单位需补充当前官方依据并记录映射，同一学校的校区不无条件当成新学校。

“院校”页同时记录基线原名、当前名称、985／211归属、基线链接、招生单位区分、覆盖年份`coverageYear`、目标专业范围、收集人、覆盖状态及证据。该页是**空白收集模板**，本次未预填或核验全国完整名单；先由名单负责人核对官方基线并冻结，再分工采集，不预设112、116或其他数字作为已核验学校总数。官方名单入口已定位，正文访问存在限制；学校当前名称、独立招生单位及2027招生目录均须在实际采集时逐校核实。同一提交批次只跟踪一个覆盖年份，跨年份应单独交付并按稳定院校编号合并。

全部学校都要覆盖基础信息，但不代表每所都有当前目标计算机专业。首轮专业范围沿用`081200／085404`，目标范围写进每校`programScope`；其他计算机相关代码单列，不因未找到这两个代码就断言学校“不招计算机”。每校须遍历相关学院及独立招生单位的当年目录，不能找到一个学院就结束。没有该范围专业时填写`VERIFIED_NONE`并提供完整目录检索范围、具体定位及复核依据；官网暂不可访问、尚未公布或条件不清记`BLOCKED`，不能填“无专业”。

覆盖完成的标准为：冻结基线中的每所学校都有对应行，`VERIFIED_FOUND`关联已复核的全部目标专业记录，或`VERIFIED_NONE`关联已复核的无目标专业证据；两类均须真实复核记录。`NOT_STARTED／IN_PROGRESS／PENDING_REVIEW／BLOCKED`仍是缺口。已查学校数、已完成学校数和招生专业条目数分别统计，不能用专业条目数冒充学校覆盖量。每个独立招生单位先保留原目录记录，合并时由负责人核对学校身份与展示映射。

“院校”保存学校名称、所在省份及可核实层次；`schoolCode`是团队稳定编号，如`SCH-AB-001`，**不是教育部院校代码**。同一学校由负责人统一编号，不因不同学院重复建校。层次未知留空，不写估计值。

“招生专业”的一行表示：学校＋学院＋招生入学年份＋专业代码＋学位类型＋学习方式＋招考类别＋方向／科目组合。同校同专业有不同学院、方向、全日制／非全日制时拆行；同一方向存在多套任选科目时也拆行并在`track`注明组合，不能把互斥的科目并成一组。各科目名称与代码按顺序一一对应，例如`101;201;301;408`对应`思想政治理论;英语（一）;数学（一）;计算机学科专业基础`。

`year=2027`表示2027年入学招生，并非公告发布年份或初试举行年份。默认先收2027、专业范围沿用当前081200／085404；其他年份和专业单列，不将往年目录当当年证据。不确定的条件写入`note`并保持待核实。报考限制、复试／加试要求必须有精确依据，不推算录取概率。

`admissionCategory=ordinary`表示普通统考，`recommended`表示推免，`special`表示专项计划。当前推荐副本没有招考类别和方向的筛选字段：**只有符合当前覆盖范围、且能无歧义表示的普通统考记录才可转换**；其余保留待适配，不能忽略类别或方向后直接混入候选。

### 3.3 知识资料：一个明确知识主题一份正文

每条知识资料对应一份Markdown，建议300—1500字，以定义、适用前提、机制／公式、简短例子、易混点组织。字数是收集建议，不是系统限制；当前Agent单条正文上限50000字符。不要人为切成450字碎片，发布时由已有检索代码切块。

`subject`使用四科中文标准名；`chapter`和`knowledgePoint`先按本文分工主题统一命名，`keywords`填3—8个相关术语，不堆入无关词。`scope`注明适用前提；翻译、节选、改编或自编分别在`adaptation`说明，并保留原文版本与定位。图、表和公式同样需要依据和使用权限；含图片、扫描件或复杂公式的材料先登记为待处理，不假定当前系统已支持OCR或图题。

### 3.4 题目：当前只收四选一单选，必须有正式答案和解析依据

题干、A—D四个选项、唯一标准答案、完整解析、知识点、难度、来源类别都要填。解析写清推理及适用条件，不能只写“答案A”。数值题检查单位和边界，选项去重；翻译题保留原题号及翻译说明，不随意创造干扰项或改变原条件。

`sourceType`只能是`REAL_EXAM`真题、`MOCK`模拟题、`ORIGINAL`团队自编、`COURSE_EXERCISE`课程习题。真题必须有年份和原题号；“考研风格”“来源于课程”“网上回忆”都不能冒充真题。自编题需要真实作者记录和人工验算；不能将AI生成内容冒充既有真实题目或人工原创。资料负责人应另核对题干、答案、解析是否分别具有相应使用依据。

当前录题限制：题干／解析各不超过10000字符；每个选项不超过2000；知识点255；来源名称255；来源定位1000；权限说明2000；原题号64。超过限制要先处理，不能导入时静默截断。难度仅为收集人的初评，不作为考生真实难度标定。判断题、多选题、综合题、图片依赖题先不纳入本模板可发布范围。

本次5表范围不单独收集历史分数线、报录比或人数指标，也不自动填充`school_detail.enrollment_count`或`score_line`。后续需要这些指标时再定义完整年份、统考／推免、校／院／专业及阶段口径，不把无口径数字塞进备注当作正式指标。

## 4. 编号、文件与交付包

负责人先为成员分配唯一前缀，避免多人都用001。推荐`SRC-AB-001`来源、`SCH-AB-001`院校、`PRG-AB-001`专业、`KN-AB-001`知识、`Q-AB-001`题目；AB替换为成员分工前缀。编号一经分配保持稳定，修订只增加`recordVersion`；同校重复编号由合并负责人建立映射。数据库数字ID由服务生成，队员不填数据库ID。

提交包示意（下列目录仅在有实际资料时建立）：

```text
collection-20261024-AB/
  资料收集模板.xlsx
  content/KN-AB-001.md
  evidence/SRC-AB-001-目录定位.pdf
  evidence/SRC-AB-002-许可说明.txt
```

`contentFile`、`filePath`和本地权限证据路径均相对于提交包根目录。只允许包内普通文件；拒绝绝对路径、`..`越界和符号链接。正文与附件以实际需要和许可范围为准。使用CSV交付时放`templates/`同名文件，空的业务表可只保留表头；负责人不得同时把Excel和CSV当两批独立数据重复导入。

## 5. 审核规则与未来导入步骤

模板中的`reviewStatus`是**收集流程状态**：`DRAFT`草稿、`PENDING_REVIEW`待审、`APPROVED`审核通过、`REJECTED`驳回、`CONFLICT`证据冲突。它不直接等于数据库状态或Agent的`verified`。`collectedBy`填真实收集人，`reviewer`与`reviewedAt`只在实际复核后填写；通过／驳回／冲突都应写清`reviewNote`。记录是否可发布还取决于全部关联来源的许可、适用条件和平台兼容性。

合并负责人按以下顺序执行；这些是**待实现／待执行流程**：

1. 离线读取模板，检查表头、日期、类型、必填项、枚举、长度、文件路径、来源外键和编号重复。按学校及招生组合查重；同一来源／原题号及近似题干另做题目重复检查。
2. 对照原文复核关键事实、标准答案与解析，检查权限覆盖具体用途。来源失效、条件冲突、许可待确认、正文越界的条目形成错误清单：文件、工作表、行号、字段、原因。不得静默跳过或把未知值变成0。
3. 生成只读预览：新增／重复／冲突／待处理数量、字段映射及无法存入当前表的字段。相同编号＋相同版本＋相同内容重复提交视为同一条；相同编号和版本但内容不同则冲突，不能覆盖。更高版本仍须审核，保留原内容。
4. 转换为Java入参和版本化Agent JSON，先在独立测试库检查。采集字段不能直接设置发布状态、active、数据库version、creatorUserId或reviewerUserId；账号身份由Java认证确定。正文中的审核备注不能伪装成真实审核账号。
5. 当前可通过管理员逐题录入，再审核；未来批量适配器也应先创建待审核记录。已发布题的修改不能通过批量覆盖旧行完成，完整不可变题目版本发布仍待建设。知识资料须完成资料审核；检索副本只包含实际批准的内容。
6. 正式入库前完成预览、备份和恢复方案，在本项目具体授权范围执行写入。新发布副本、引用域名策略与索引需配套验证；保留旧版本供回滚，不能改写历史快照。

## 6. 与现有系统的映射及限制

| 收集表 | 当前落点／转换方式 | 尚不能直接落地的部分 |
| --- | --- | --- |
| 来源 | 导入时关联到题目六个来源字段、资料来源说明、Agent引用元数据 | 当前没有独立完整来源登记表；保留提交包和审核清单，不能假装所有元数据已入库 |

| 知识资料 | Markdown读取为`document.content`；发布后另生成Agent `domain=knowledge`副本 | 仅写`document`不会自动进入RAG；知识点层级、许可、版本需保留发布清单 |

Agent现有格式必须包含`id/domain/title/url/locator/version/retrievedAt/license/content/reviewStatus`，知识可含`subject/keywords`；招生`metadata`必须包含`programId/school/college/major/majorCode/year/degreeType/region/studyMode/examSubjects/updatedAt`。审核后才转换为`reviewStatus=verified`；`license`须描述实际获准的拟用方式。多个来源不能被简单丢成一个链接：转换时拆分可独立引用的事实摘要，保留所有证据映射。

`releaseId`由现有语料内容计算，队员不填；题目答案和解析不放入学生未答题详情或公开知识索引。新增引用域名必须先审核共享`config/reference-hosts.json`，Java／Python同步加载；不能通过放宽域名校验“解决”来源失败。Python继续只读版本化副本和独立Qdrant，不连接业务库。
