# 资料收集字段字典

版本：collection-v3。共5张数据表，院校覆盖字段并入schools.csv；Excel另保留分工与说明、题库配额、字段字典3张辅助页面，不作为导入数据。历史指标不在本次范围。必填表示进入待审／发布前的要求，草稿允许留空。审核与权限不因填了状态自动成立。完整流程见[收集规范](README.md)。数据页第1行为机器字段，第2行为中文名称，第3行起填写；CSV仅保留机器表头。

## 来源（sources.csv）

| 字段 | 名称 | 必填 | 类型 | 规则及允许值 |
| --- | --- | --- | --- | --- |
| `sourceId` | 来源编号 | 是 | text | SRC-成员前缀-序号；稳定且全包唯一 |
| `sourceKind` | 来源类型 | 是 | text | 来源性质，与题目来源类别分别填写；允许值：OFFICIAL_ADMISSION / TEXTBOOK / COURSE / OPEN_RESOURCE / ORIGINAL_RECORD |
| `title` | 来源标题 | 是 | text | 准确书名／公告／讲义名称；题目转换来源名最多255字符 |
| `author` | 作者或机构 | 是 | text | 按原文署名，不编造原创作者 |
| `url` | 具体原文链接 | 条件 | text | 无凭证HTTPS具体页；url与filePath至少一项；Agent目前必须有可引用HTTPS链接 |
| `locator` | 原文定位 | 是 | text | 章节／页码／表格行／原题号／动态查询条件 |
| `sourceVersion` | 原文版本 | 是 | text | 官方文件版本、教材版次或明确标注的采集快照版本 |
| `publishedAt` | 原文发布日期 | 否 | date | 查不到留空，不以获取日期替代 |
| `retrievedAt` | 实际获取日期 | 是 | date | YYYY-MM-DD，不填未来日期 |
| `permissionStatus` | 权限状态 | 是 | text | 只表示拟用方式，权限未知不可发布；允许值：PENDING / ALLOWED / LINK_ONLY / PROHIBITED |
| `permissionNote` | 允许用途及署名 | 是 | text | 具体拟用方式、署名与限制；非空不等于许可已核验 |
| `permissionEvidence` | 权限证据 | 通过时 | text | 许可页HTTPS或包内授权记录路径；不得填写秘密凭证 |
| `filePath` | 原文证据文件 | 条件 | path | 包内普通文件相对路径；与url至少一项；按许可留存 |
| `fileSha256` | 证据SHA-256 | 否 | text | 合并负责人针对filePath实际文件计算64位十六进制值 |
| `recordVersion` | 采集版本 | 是 | integer | 从1开始；内容修订增加；不是数据库题目version |
| `collectedBy` | 收集人 | 是 | text | 真实成员姓名或团队可识别代号 |
| `reviewStatus` | 收集审核状态 | 是 | text | 收集流程状态，不直接设置数据库发布状态；允许值：DRAFT / PENDING_REVIEW / APPROVED / REJECTED / CONFLICT |
| `reviewer` | 复核人 | 审核后 | text | 真实复核人；未复核留空 |
| `reviewedAt` | 复核日期 | 审核后 | date | 实际复核日期；YYYY-MM-DD |
| `reviewNote` | 审核说明 | 审核后 | text | 说明复核范围、依据及问题；驳回／冲突须具体原因 |

## 院校（schools.csv）

| 字段 | 名称 | 必填 | 类型 | 规则及允许值 |
| --- | --- | --- | --- | --- |
| `schoolCode` | 院校采集编号 | 是 | text | SCH-成员前缀-序号；不是教育部院校代码 |
| `name` | 学校全称 | 是 | text | 对应school.name；最多255字符 |
| `province` | 省份或直辖市 | 是 | text | 与现有库地区选项统一，例如江苏、北京 |
| `level` | 已核实层次 | 否 | text | 对应school.level；未知空；可核实时只填适用的最高展示分类；允许值：985 / 211 / 双一流 / 普通高校 |
| `sourceIds` | 来源编号 | 是 | list | 关联来源页；多个编号用英文分号分隔，第一项为主来源 |
| `locator` | 逐字段来源定位 | 是 | text | 具体页码／章节／表格行；多来源写 字段=来源编号@位置 |
| `baselineName` | 官方基线原名 | 是 | text | 保留官方985／211名单中的原名称，以便核查映射 |
| `is985` | 985归属 | 是 | text | 须按官方分类名单核对；UNKNOWN表示待核实；允许值：YES / NO / UNKNOWN |
| `is211` | 211归属 | 是 | text | 不把双一流自动当211；UNKNOWN表示待核实；允许值：YES / NO / UNKNOWN |
| `baselineUrl` | 基线名单链接 | 是 | text | 教育部官方985／211分类名单具体页；多链接用英文分号 |
| `unitNote` | 校区及招生单位区分 | 条件 | text | 记录更名／合并／校区与独立招生单位映射及其证据，不预设学校计数 |
| `coverageYear` | 覆盖招生年份 | 是 | integer | 默认2027；对应逐校当年目录 |
| `programScope` | 本校目标专业范围 | 是 | text | 首轮081200／085404；如扩充其他计算机专业须明确代码，不偷换无专业含义 |
| `coverageStatus` | 覆盖进度 | 是 | text | 学校查全后才可记录VERIFIED_FOUND或VERIFIED_NONE；访问受限不是无专业；允许值：NOT_STARTED / IN_PROGRESS / PENDING_REVIEW / VERIFIED_FOUND / VERIFIED_NONE / BLOCKED |
| `programIds` | 本校目标专业条目 | 找到时 | list | 关联招生专业页；多个PRG编号用英文分号；须覆盖全部目标学院／方向 |
| `evidenceSourceIds` | 覆盖核验来源编号 | 完成时 | list | 关联来源页，特别是无目标专业的完整目录检索证据 |
| `coverageLocator` | 检索范围及证据定位 | 完成时 | text | 遍历的学院／招生单位／年份／目录行及条件，不只写未搜到 |
| `coverageNote` | 缺口及补充说明 | 条件 | text | 未公布／访问受限／更名歧义写明；未解决不能算全量完成 |
| `recordVersion` | 采集版本 | 是 | integer | 从1开始；内容修订增加；不是数据库题目version |
| `collectedBy` | 收集人 | 是 | text | 真实成员姓名或团队可识别代号 |
| `reviewStatus` | 收集审核状态 | 是 | text | 收集流程状态，不直接设置数据库发布状态；允许值：DRAFT / PENDING_REVIEW / APPROVED / REJECTED / CONFLICT |
| `reviewer` | 复核人 | 审核后 | text | 真实复核人；未复核留空 |
| `reviewedAt` | 复核日期 | 审核后 | date | 实际复核日期；YYYY-MM-DD |
| `reviewNote` | 审核说明 | 审核后 | text | 说明复核范围、依据及问题；驳回／冲突须具体原因 |

## 招生专业（programs.csv）

| 字段 | 名称 | 必填 | 类型 | 规则及允许值 |
| --- | --- | --- | --- | --- |
| `programId` | 招生条目编号 | 是 | text | PRG-成员前缀-序号；稳定标识具体招生组合 |
| `schoolCode` | 关联院校编号 | 是 | text | 必须存在于院校页；负责人合并时统一映射 |
| `college` | 学院全称 | 是 | text | 不同学院必须拆行，不只填学校名 |
| `majorCode` | 六位专业代码 | 是 | text | 6位文本，保留前导0；例如081200 |
| `major` | 专业名称 | 是 | text | 目录原文全称；对应school_detail.major_name |
| `year` | 入学招生年份 | 是 | integer | 2000—2100；例如2027；不是公告年份 |
| `degreeType` | 学位类型 | 是 | text | academic=学硕；professional=专硕；允许值：academic / professional |
| `studyMode` | 学习方式 | 是 | text | full_time=全日制；part_time=非全日制；允许值：full_time / part_time |
| `admissionCategory` | 招考类别 | 是 | text | ordinary普通统考；recommended推免；special专项；后两者当前不进推荐副本；允许值：ordinary / recommended / special |
| `track` | 方向及科目组合 | 条件 | text | 无方向差异时空；不同方向或任选科目组合必须拆行并注明 |
| `examSubjects` | 初试科目代码 | 是 | list | 三位文本代码，英文分号分隔；每个统考组合通常4项，不合并互斥选项 |
| `examSubjectNames` | 初试科目名称 | 是 | list | 与代码按顺序一一对应；分隔符英文分号 |
| `eligibility` | 报考及加试条件 | 条件 | text | 有官方依据才填；缺失时在note标待核实，不推断无条件限制 |
| `note` | 条件缺口及备注 | 条件 | text | 查不到资格／动态页面失效／特殊限制等如实记录；不填录取概率 |
| `sourceIds` | 来源编号 | 是 | list | 关联来源页；多个编号用英文分号分隔，第一项为主来源 |
| `locator` | 逐字段来源定位 | 是 | text | 具体页码／章节／表格行；多来源写 字段=来源编号@位置 |
| `recordVersion` | 采集版本 | 是 | integer | 从1开始；内容修订增加；不是数据库题目version |
| `collectedBy` | 收集人 | 是 | text | 真实成员姓名或团队可识别代号 |
| `reviewStatus` | 收集审核状态 | 是 | text | 收集流程状态，不直接设置数据库发布状态；允许值：DRAFT / PENDING_REVIEW / APPROVED / REJECTED / CONFLICT |
| `reviewer` | 复核人 | 审核后 | text | 真实复核人；未复核留空 |
| `reviewedAt` | 复核日期 | 审核后 | date | 实际复核日期；YYYY-MM-DD |
| `reviewNote` | 审核说明 | 审核后 | text | 说明复核范围、依据及问题；驳回／冲突须具体原因 |
