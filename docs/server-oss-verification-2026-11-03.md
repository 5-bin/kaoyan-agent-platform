## 实现与兼容

新增 `OSS_KEY_PREFIX`，本机默认空、线上为 `prod/`。新对象键为 `prod/{module}/{userId}/{日期}/{随机名}.{扩展名}`，头像使用avatar模块。前缀允许ASCII目录段，拒绝穿越、协议、反斜杠、空段和超长值；规范为单个尾斜杠。上传、头像新绑定、认证读取和删除统一使用该目录，URL拼接不再次添加前缀。

空前缀保留本机旧头像读取及保留绑定行为；非空前缀拒绝其他环境目录、无归属旧路径及其他账号的新绑定／删除。当前绑定头像仍返回409，要求先更换。`POST /api/files/upload`仍返回url和objectKey，现有图片扩展名与5MB限制不变，不增加PDF等附件。图片内容仍按原扩展名校验，不宣称完成图像内容安全检查或孤立对象自动清理。

SDK上传输入流改为显式关闭；上传／读取／删除的SDK及网络异常转换为固定错误信息，OSS配置对象的toString不包含AccessKey ID或Secret。前端及Python代码和运行文件保持此前线上字节内容，本次不涉及数据结构或模型接口变更。
