## 待审核边界

原有16道自编题仍为PENDING_REVIEW，未填写虚假审核人或审核时间，也未发布到学生抽题接口。模拟已答记录保存完整题目版本快照，并标注fixture来源；不是从当前题目补造任何真实用户的历史记录。

未答的2条指向待审核题，接口返回UNAVAILABLE且不返回标准答案；因此该批次可用于检查不可练习提示，不能当作可继续作答的正式批次。新增刷题与重练仍需管理员通过正常审核流程发布题目。本次没有创建管理员、提权或代替人工审核。

个人文档是用户材料，未进入公共审核资料或Agent检索库。文档版本的source_task_id为NULL，不冒充AI生成后保存的版本。模拟任务没有RUNNING状态，不会触发后台模型调用。

## 数据文件和重复执行

- [功能夹具](../scripts/fixtures/feature-test-data.json)：固定日期、模拟答案、收藏代码、文档版本和任务样例。
- [导入脚本](../scripts/seed-feature-test-data.py)：默认预览；`--apply`才备份、注册测试账号并插入数据。仅允许本机数据库，使用根`.env`的已有连接配置；要求已有V7—V11结构，不执行迁移。

从本项目根目录执行：

```bash
.cache/chat-venv/bin/python scripts/seed-feature-test-data.py

# 仅在已授权的本机测试范围内执行写入。
.cache/chat-venv/bin/python scripts/seed-feature-test-data.py --apply
```

脚本复用本机私密凭据，不打印密码或令牌，不接管同名既有账号，不重置密码或改变角色。首次写入前核对引用题目与原始夹具一致，避免把人工修改后的内容冒充夹具快照。

批次和文档／任务编号固定，重复执行不重复插入、不覆盖已存在历史或文档；后续手工增加、移除或编辑记录后，固定数量检查可能提示差异，不会自动删除或覆盖操作结果。脚本不用于日常数据同步或重置。
