# 骨架部署配置

当前提供Compose和Dockerfile，**尚未运行Docker、PostgreSQL、HTTPS或公网部署**。本机验证以H2、演示模式和临时进程为准。

## 本地容器预览

需要Docker Compose。先按[README](../README.md)生成.env，确认内部凭证和数据库密码，然后在项目根目录执行：

```bash
docker compose config --quiet
docker compose up --build -d
docker compose ps
```

Java只映射127.0.0.1:8080，Python和PostgreSQL无宿主端口。database-data卷保留业务数据；普通down保留卷，不用删卷参数清理配置问题。容器数据库与本地H2独立。

## 公开入口与后续工作

服务器、域名与费用确定后，在授权范围内配置SITE_ADDRESS，开放80/443并启动public profile，Caddy负责HTTPS。当前没有发布应用网站，也没有申请证书。

正式上线前需完成领域业务、入口限流、真实模型验证、数据库迁移及备份恢复。当前Hibernate update不是正式迁移策略；管理员初始化工具与知识发布卷尚未实现。

备份应包含数据库及将来启用的资料版本包，在独立恢复库验证关联与历史引用；不要用验收覆盖业务库。当前KNOWLEDGE_RELEASE_DIR未实现，不添加无效环境变量。
