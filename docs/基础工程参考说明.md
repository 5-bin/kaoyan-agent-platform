# 基础工程复用与参考边界

本项目按用户要求，选择性复用本地“领域Agent基础工程”的账号、任务、模型适配、构建模板与验证脚本，扩展为考研平台的独立仓库。参考工程保持原位；数据库、.env、缓存、虚拟环境和历史报告均未复制。

原始参考工程在本工作区的`Projects/领域Agent基础工程/`，它不是本仓库的一部分。为使仓库独立阅读，搭建文档中的本地参考链接已调整到本项目实际文件和本说明；没有假设读者拥有另一个项目目录。

## 历史验证与当前验证

参考工程的历史验证只证明它当时的工程行为，不证明本仓库或领域软件完成。本项目的运行方法见[README](../README.md)，当前接口见[接口约定](接口约定.md)，本次实际结果见[验证记录](验证记录.md)。

参考工程任务与学习模板中的日期、身份、博客、发布授权和成绩不继承到本项目。课程信息以真实通知及用户提供内容为准。
