## 来源与权限

只整理招生事实短摘要、公开链接和原文定位，不复制官网整页或原始目录进入代码仓库，不取得或声称拥有第三方题库、教材或官网内容的再分发许可。动态查询属于公开只读信息查询，不提交报名、登录或招生业务变更。

层次字段是互斥展示标签，不表示985、211、双一流在现实中互斥。未登记学校层次保留NULL，不等同于断定其“普通”或“不属于双一流”。科目代码、学院和年份逐记录保存，不依靠学校名称推断。

## 原创题与知识资料

[160道原创练习题和12道审核样例](../scripts/fixtures/feature-2027-questions.json)由[编排脚本](../scripts/feature_fixture.py)生成，可重复校验；非历年真题。每科20道概念题、20道带算例核验的计算／操作题，难度为16简单、16中等、8困难；难度仅是测试分组，不是实测难度或学习效果指标。

题干、选项与解析为本项目自编。概念依据为常规408知识，计算题以题干给定条件为准；复算器限定运算名称及参数，不执行夹具提供的代码。独立示例覆盖FIFO的Belady异常、哈夫曼合并、补码、子网和Amdahl加速比；答案篡改、重复编号和非法核验类型应被拒绝。自动校验与测试管理员发布不冒充教师或人工审核。

可追溯的基础参考入口：[OSTEP作者版](https://pages.cs.wisc.edu/~remzi/OSTEP/)、[TCP RFC 9293](https://www.rfc-editor.org/rfc/rfc9293)、[RISC-V官方规范](https://docs.riscv.org/reference/isa/unpriv/rv32.html)。未复制其中的习题、图表或原文，不声明这些入口覆盖或人工审核了全部160题。

独立环境另使用同项目已有4段知识短摘要供资料浏览和离线问答；保留原来源和原核验日期，本轮没有将其描述为新完成的内容审核。题库与这4段摘要不是完整408教学知识库，模型保持关闭。
