# 笔记列表内部滚动与展开验证

日期：2026-10-23。按用户要求，将`/notes`笔记列表改为内部滚动并逐批展开，沿用会话列表每批5条的交互。具体规则见[连续聊天与个人文档契约](conversations.md#笔记列表展开)，页面能力同步至[搭建文档](../考研Agent平台搭建文档.md)。

## 修改范围

- `PersonalNotes.vue`：卡片内笔记条目单独滚动，新建及展开按钮位于滚动区外；默认5份，每次追加5份，末页隐藏按钮，加载时防止重复请求，失败保留已有条目并可重试。
- 笔记列表请求独立于当前笔记详情；切换保留已展开页数和滚动位置，分页加载中切换仍接收有效结果。保存及助手更新按已加载页数刷新，退出、账号切换及卸载隔离迟到响应；页面刷新恢复5份。
- `listPersonalDocuments`允许显式指定分页大小，默认仍为20；仅笔记页传5，聊天笔记选择及历史版本保持原分页。没有修改后端、接口字段、数据库或用户记录。
- 在已有`tests/notes.spec.ts`中增加边界数量、滚动、切换、保存、失败及账号隔离回归；保留当前工作区已有会话相关修改。
