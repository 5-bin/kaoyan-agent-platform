# 助手组题与站内导航验证

日期：2026-10-25。范围：当前项目的Python意图识别、Java练习操作及可信导航、Vue聊天卡片与安全Markdown。保留原有诊断学情及资料收集等未提交修改，不创建分支、提交、推送或执行迁移。

## 本轮行为

- “给我出几道有关排序的题”“出5道排序题”“从收藏里出5道排序题”等明确请求走审核题库组卷规则，默认5题；不调用模型生成题目。主题不明确、数量无效、否定或功能咨询不生成创建操作。
- Java固定候选与题量，返回待确认卡片。点击“开始练习”调用既有确认接口，成功后进入正式答题页；确认前不创建批次，重复与并发确认返回同一批次。成功卡片提供“继续练习”。缺题显示实际数量，零匹配与索引未就绪不显示开始操作；409保留预览并要求重新组题，网络失败允许重试。
- 题目预览、学习依据与组题后的收藏按钮默认折叠。正文使用实际组卷题量，不把全部检索命中量写成已组题量。
- `config/assistant-navigation.json`是11个固定入口的共享配置（9个普通入口、2个管理入口）；Java重新生成导航，前端过滤当前角色并渲染正文链接及入口按钮。旧聊天可补充入口，不回写历史。代码、已有链接、笔记草稿不自动替换；来源URL仍需本轮授权，任意站内路径、未授权外链和危险协议被拒绝。
- 无新增数据库表、任务类型、终态或付费调用。本机现有模型及学习开关沿用原配置。

契约以[搭建文档](../考研Agent平台搭建文档.md)和[学情助手契约](assistant-learning-contract.md#助手组题与站内导航2026-10-25)为准。

## 测试中修正的问题

- 两端原规则漏识别“出几道有关排序的题”：Python补充主题／数量之间允许插词的匹配，Java同步允许明确“出…题”请求，并保留否定、咨询与澄清保护。
- 泛指“几道题”中的量词可能被识别成主题，已排除；排序和查找等多主题请求要求明确主题。
- DOMPurify默认清除外链`target`，本轮仅保留渲染器生成的该属性，来源链接继续使用`_blank`和`noopener noreferrer`。
- 原诊断隔离测试假定抽中的首题答案始终是B，但共享夹具中已有修订题；改为从测试数据库读取实际选中题的答案。未更改判分业务逻辑或放宽断言。
- Java复验曾随机选中与本机IDE相同的端口，客户端收到IDE的404。聊天隔离测试现显式绑定`127.0.0.1`，与其HTTP客户端地址一致，避免回环地址族不一致。咨询表达补充保护后重新执行全量验证。
