## 修复行为

- 同一基线五个不同字段全部一致且无实质限制时返回 `CONSISTENT`。有明确变化使用 `DIFFERENCES`，证据不足或冲突使用 `PARTIAL`，无证据使用 `UNAVAILABLE`，缺条件或同年基线使用 `NEEDS_INPUT`。
- 资格条件、研究方向和“未发现不代表停招”改为即时结果的固定 notice，并由历史结果组件固定展示；不新增字段，不修改历史 JSON。Python 与 Java 拒绝缺字段、重复字段、跨基线和带阻断限制的伪造一致结果。
- 完整处理当前 HTML 全部匹配行或当前 PDF 后，五字段有唯一值即停止，不再抓取后续首页和公告；同页冲突继续保留。导航无专业表不形成阻断限制，目录读取失败及实际缺字段仍提示。PDF 数量、HTTP 次数、超时、取消、域名及公网地址策略保持原约束。
- 自然问法“帮我查询北京航空航天大学招生信息”由本地路由处理，仅追问缺条件。北大、清华及其全称提示未登记及登记名单，不调用模型或取证工具。“可以查询哪些学校官网”确定性返回学校与官方入口，明确登记不等于均可自动解析。
- 模型提示词禁止产生招生联网动作；模型专用计划校验在嵌套招生参数解析前，将该动作或非空招生参数转为 `CHAT` 与招生澄清，清除模型附带的读写操作。Java 保留独立判断与来源校验，空白澄清不能绕过完整查询要求。

需求与契约以[搭建文档](../考研Agent平台搭建文档.md)为主，结果说明见 [RAG 契约](rag.md)，路由说明见[会话契约](conversations.md)。原 HTML／PDF 记录保留为各自时点的历史证据。

## 环境与执行方式

本机 macOS，Python 3.13.15（本项目现有 `.cache/mcp-pdf-venv`）、Java 25.0.4.1（工程目标 Java 17）、Node.js 22.23.3，浏览器使用本机 Chrome 的独立临时上下文。未读取日常浏览器资料。

从项目根目录执行：

```bash
(cd kaoyan-agent && ../.cache/mcp-pdf-venv/bin/python -m pytest -q)
(cd kaoyan-B && PYTHON_EXECUTABLE="$PWD/../.cache/mcp-pdf-venv/bin/python" bash mvnw -B verify)
(cd kaoyan-frontend && npm run build)
(cd kaoyan-frontend && PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm run test:e2e -- admission.spec.ts clarification.spec.ts)
git diff --check
```

本机 Maven Wrapper 文件无执行权限，使用 `bash mvnw`，未更改文件权限。Java 链路测试需通过已有 `PYTHON_EXECUTABLE` 入口指定解释器；首次未设置时因找不到 `python` 导致 34 项初始化错误，设置后全量通过。Chrome 首次在沙箱内启动以 SIGABRT 退出；获自动批准后，在沙箱外使用临时上下文完成相同测试，预览仅绑定回环地址，所有业务 API 均为模拟响应。
