## 实现范围

- 管理页新增JSON示例下载、UTF-8文件选择／粘贴、服务端预览和明确确认送审。每批1—50题，界面文件上限2MiB。8道示例覆盖408四科，每科2题，均标注自编、非真题，待人工审核；不自动导入。
- 两个ADMIN专用POST入口：`/api/questions/admin/import/preview`与`/api/questions/admin/import`。先校验全批，再在单事务中写入；规范化答案和首尾空白，固定待审核版本1，发布与审核字段不接受客户端设置。
- 业务错误标记从1开始的题号；完整匹配科目、题干和四个选项，拦截批内重复与已存在题；既有题目不覆盖。输入变化使预览失效，导入失败保留输入并要求重新校验，网络不明时提示先查看待审记录，不自动重试。
- 不增加数据库表或迁移，不访问Python或模型。仍需先具有V9来源字段；不执行旧种子脚本，不影响已保存作答快照。

## 未运行与限制

- 本轮未向日常MySQL实际导入、未运行真实用户人工导入验收、未调用真实模型、未部署线上。浏览器API替身不等于真实数据库页面全链路；Java事务回滚依据隔离H2结果，MySQL环境仍需实际验收。
- 精确重复检查依赖当前表查询及数据库排序规则，没有新增唯一索引或持久幂等请求表；并发录入可能竞态，不能宣称跨实例幂等。单题录入沿用原行为，未增加去重。不同措辞、选项顺序、图片或公式等不保证识别为重复。
- 暂不支持Excel／CSV／PDF、OCR、自动采集、整卷／年份筛选、逐行部分成功、批量自动审核或已发布题新版本修订。真实题源由团队核对授权与内容，示例数量不代表完整题库。
- Java源代码已验证，但用户日常运行进程仍需手动重启加载；本轮隔离构建没有替换其正在使用的JAR。前端开发服务器可自动刷新源码，调用新接口前需加载新版后端。
