# 助手主题筛选与澄清问法验证

日期：2026-10-23。范围：当前 adaptation 工作区，不提交、推送或部署，不修改日常数据库，不重启已有服务。

## 修改与依据

用户原始请求为“将我错题本中涉及tcp协议内容的部分加入我的收藏”，实际提示却要求从17道候选中补充Q编号。代码检查发现：本地解析未识别小写tcp；收藏目的被并入读取集合；目标默认selected导致历史候选消歧；Java知识点只按完全相等筛选，TCP不能匹配TCP拥塞控制和TCP序号。

- Python将来源集合与写入目的分开，规范大小写、空白和协议别名；保留完整子主题。未知或多主题条件要求澄清，支持通过“知识点：主题名称”明确指定。
- Java明确集合请求直接读取本人当前集合，不继承无关页面选择、科目、批次或历史候选；读取与操作复核复用同一主题比较。跨轮Q引用规则保留。
- 多题收藏展示PENDING预览后确认；最多50题，超过限制提示总量及未纳入数量。未匹配不生成操作。
- 需求不明确时说明缺失条件并给出“推荐问法”。Python回复及Java目标消歧、零匹配分支均覆盖；示例不授权执行。Java对所有澄清计划清空读写操作及页面目标，避免不完整请求继续生成操作。
- 契约见[学情助手增量契约](assistant-learning-contract.md)。公开接口、数据库结构和前端未变更。
