# 原型构建底稿

这两份文件来自本项目工作区已有的 `原型设计/prototype-export/` 中 14 份静态 HTML，按原 `build.py` 的处理过程在 2026-11-05 整理，作为 v2 原型的仓库内构建输入。

- `templates.json`：以原页面名称为键的页面 DOM；已清除脚本、临时浮层、注释和密码字段初始值，保留页面使用的样式属性。
- `styles.css`：按原构建顺序去重后的快照内联样式。

两份底稿只用于本原型的视觉模板，业务交互在上级 `prototype.js` 中实现，额外样式在上级 `prototype.css` 中。整理没有改变已验收页面的生成内容。

重建直接读取本目录，不再读取仓库外的原始导出目录，也不需要 BeautifulSoup4 或 tinycss2。完整命令见 [交付说明](../../README.md)。
