## 1. 映射口径


持久化分为MyBatis-Plus实体/Mapper和直接JDBC两类：10张表有@TableName实体，18张表没有传统实体或专属Mapper，经ChatRepository（内部JdbcTemplate）或独立JdbcTemplate服务访问。LearningContracts中的record和AdmissionMetricsVO是请求、响应或计算结构，不是ORM实体。

链接固定到本文提交；类路径属于kaoyan-B/src/main/java/com/kaoyan。Python Agent不直接访问这28张表，只处理Java授权快照和独立检索资料。

## 3. 实体字段到SQL列（10表逐项）


map-underscore-to-camel-case:true支持普通驼峰映射；@TableName指定表名，User对user使用反引号。自增主键为IdType.AUTO，Task.id为IdType.ASSIGN_UUID，JDBC主键由服务生成。

Java Long为有符号64位，不能覆盖SQL BIGINT UNSIGNED全部上界；Integer对应INT及当前TINYINT标志，BigDecimal对应DECIMAL，LocalDate对应DATE，LocalDateTime对应DATETIME。可空和约束仍看SQL。

实体createdAt/updatedAt由MyMetaObjectHandler填充；数据库默认与ON UPDATE独立存在，不能把Java填充值写为DDL DEFAULT。

## 5. 持久化链与交接说明


| 业务 | 实际链路 | 核对要点 |
| --- | --- | --- |
| 账号档案 | UserServiceImpl→UserMapper→user；隐私与配额还直接锁user行 | V15 degreeType已映射；user档案文本非院校外键 |
| 任务与推荐 | TaskServiceImpl/TaskStore→TaskMapper→task；RecommendServiceImpl委托TaskService | 隐藏不退额度，旧recommend_record非新历史来源 |
| 平台资料 | DocumentServiceImpl→DocumentMapper→document | 审核资料和个人笔记分开 |
| 院校目录 | School/SchoolDetail服务→Mapper；SchoolCatalogService调用SchoolAdmissionMetrics | V14只读扩充响应；缺表兼容不自动迁移 |
| 连续聊天 | ConversationService→ChatRepository→chat三表；TaskStore维护task | 用户输入与助手生成分表；重试、幂等和活动唯一键 |
| 个人笔记 | PersonalDocumentService→ChatRepository→personal_document及version | baseVersion检查及source_task_id幂等 |
| 隐私授权 | AssistantPrivacyService→ChatRepository→assistant_privacy，直接更新task | provider和version绑定，无授权不外发 |
| 助手操作 | AssistantLearningService→JdbcTemplate→assistant_action，再调标记/练习服务 | 按用户、会话、任务联表核验，操作白名单 |
| 练习闭环 | PracticeServiceImpl→ManagedPracticeService；PracticeRecordMapper与ChatRepository分工 | session/item/request/version表支持固定快照、草稿、提示、幂等 |
| 学情画像 | LearningProfiles读取有效作答与提示→LearningProfileEngine计算→profile/history；LearningWorker读event | blueprint分组权重，record为DTO；lease_until保留未用 |
| 自动推荐 | LearningRecommendations/Profiles→settings；TaskStore→task；读school_historical_metric | 远程规则调用在短事务外，run_token/revision控制接纳 |
| 统计展示 | StudyStatServiceImpl从有效practice_record计算 | 保留study_stat.accumulate，未记录分钟返回NULL |
