## 2. 依据与方法

- 结构依据：`kaoyan-B/src/main/resources/db/` 中的 `V1__init.sql` 与 `V7`—`V15`。`V2`—`V6` 只有 `INSERT`／`DELETE`，按旧演示种子处理，不计入结构。
- 访问依据：10 个实体与 Mapper、`SchoolMapper.xml`，以及使用 `JdbcTemplate` 的 `ChatRepository`、`ConversationService`、`PersonalDocumentService`、`AssistantPrivacyService`、`AssistantLearningService`、`SchoolAdmissionMetrics` 和 `learning/` 包。
- 外部存储依据：`ExportCache`、`JwtService`、`OssUtil`、`QuestionSearchService`、`kaoyan-agent/config.py`、[RAG 契约](../../rag.md)。
- 方法：只读源码和 SQL，未执行任何 SQL，未连接数据库。

**表数量核对：** V1 建 10 张；V10 建 3 张；V11 建 2 张；V12 建 2 张；V13 建 10 张；V14 建 1 张，合计 28 张。V7、V8、V9、V15 只增加列或约束。

## 6. 图源渲染

图源与 T04 一致使用 PlantUML，并声明 `!pragma layout smetana`，只需 Java 和 `plantuml.jar`，不依赖 Graphviz。导出文件名取自 `@startuml` 后的标题。在 `docs/coursework-02/database/er/` 下分别执行（同一条命令写两个格式参数时只生效后一个）：

```bash
java -Djava.awt.headless=true -jar plantuml.jar -charset UTF-8 -tpng -o export *.puml
```

```bash
java -Djava.awt.headless=true -jar plantuml.jar -charset UTF-8 -tsvg -o export *.puml
```

2026-11-05 使用 PlantUML 1.2024.7（Maven Central，SHA-1 `cb57b315d96413d55622edaa8c4b234e2ebf4b1f`）导出 `er/export/` 下 6 张 PNG 和 6 张 SVG，供 T12 排版使用。总览图为可读性省略了各表指向 `user` 的归属连线，改在图内注释说明；归属连线见分域图。
