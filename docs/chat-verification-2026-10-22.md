## 实现修正与复现

实际联调发现Java HttpClient默认HTTP/2升级尝试与当前Uvicorn组合导致请求422，已将内部流式客户端固定为HTTP/1.1。增量投影测试使用真实LangChain与SDK消费预先定义的供应商流块，包含中文、转义与跨块JSON；首个增量到达时供应商尚未结束，不是完成答案拆字播放。引用失败回退时不保留临时模型答案。

日常使用按README迁移并更新服务。可用独立虚拟环境执行Python测试，设置PYTHON_EXECUTABLE后运行Java verify；前端执行npm run build与npm run test:e2e。真实流式和重启复现使用`python scripts/smoke-chat.py --output 新报告.json`；额外期限检查使用`--skip-browser --timeout-check`。上述脚本拒绝覆盖已有报告，并仅清理自身进程。
